## Model File
This project uses a pre-trained model file `similarity.pkl`.

Because GitHub has a 100MB upload limit,  
the model is stored on Google Drive and automatically downloads  
when you run the project.

Manual download link:  
[Download similarity.pkl](https://drive.google.com/file/d/1xHYn_kPo5eu82_g6oTo2KkfzVYQIUCEX/view?usp=sharing)
